# Detecção de Anomalias em Transações

Projeto desenvolvido durante o bootcamp da DIO, com foco na
detecção de transações fraudulentas utilizando Python e Machine Learning.

## Objetivo

Desenvolver e avaliar modelos capazes de identificar transações
fraudulentas em operações de cartão de crédito.

## Dataset

O projeto utiliza o dataset Credit Card Fraud Detection.

O conjunto possui 284.807 transações, sendo:

- 284.315 transações normais
- 492 transações fraudulentas

A classe fraudulenta representa aproximadamente 0,17% dos dados,
caracterizando um problema de forte desbalanceamento.
